\# AI-Based Wi-Fi Signal Mapping and Intelligent Router Placement



\## Project Overview



This project is an AI-based Wi-Fi signal mapping system that analyzes Wi-Fi signal strength using RSSI (Received Signal Strength Indicator) values.



The system collects Wi-Fi signal measurements and presents them through a web-based dashboard. It helps identify weak-signal areas and provides recommendations for better router placement.



\## Main Features



\- Wi-Fi signal strength measurement

\- RSSI analysis

\- Wi-Fi signal visualization

\- Weak signal/dead-zone detection

\- Signal mapping

\- Router placement recommendation

\- Web-based dashboard

\- Automatic Wi-Fi measurement

\- Flask-based backend
